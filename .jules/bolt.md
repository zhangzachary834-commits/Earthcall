## 2026-09-17 - Pointer-based Fast Path for State Fact Seeding **Learning:** `LawManager::tick()` invokes `seedStateFacts` on every `Singular` in `Universe::instance().beings()` every frame. Previously, `seedStateFacts` performed `being->getIdentifier()` (a virtual call returning `std::string` by value) and an `unordered_set<std::string>` lookup on every being per tick. **Action:** Maintain a `std::unordered_set<const Singular*> _seededBeingPointers` to provide an $O(1)$ scalar fast-path check, bypassing string heap allocations and string hashing on hot tick loops.

## 2026-09-18 - String-View Pointer Map Lookup for Vocabulary Indexing **Learning:** `LawManager::refreshVocabularyIndex()` iterates over all `beings` and their properties during index rebuilds. Previously, it constructed a temporary `std::string` per property per being to insert/lookup in `_vocabularyIndex`. Pre-populating vector pointers into a `std::unordered_map<std::string_view, std::vector<Singular*>*>` eliminates string allocations and inner-loop map lookups during index generation. **Action:** For index building loops where key sets are known prior to scanning, map `string_view` keys directly to stable target container pointers.
