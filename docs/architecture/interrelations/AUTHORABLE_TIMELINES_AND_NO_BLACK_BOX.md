## The Interrelation

The `../ontology/TIME_AND_MOMENT.md` document establishes that Time is not a single hardcoded global clock, but rather that `Timeline`, `Moment`, and `Event` are distinct, first-class `Singular`s. Singulars can own their own Timelines, and these Timelines hold Moments and advance independently.

The `../ontology/NO_BLACK_BOX.md` doctrine demands that all meaningful state of a being must be registered as legible, addressable Properties so that Laws can interact with them. No engine state can be hidden from the authored reality.

These concepts interrelate because an authored Timeline is useless if its current coordinate or progression rate is hidden inside a C++ clock mechanism.

### Thoughts on Integration

For a Law to govern or react to time—for instance, to pause a specific Timeline during a conversation, or to reverse a Timeline to undo an action—the "current time" (`now`), the rate of change (`delta`), and the collection of `moments` must be exposed as standard Properties on the `Timeline` Singular.

"No Black Box" ensures that these temporal properties are exposed just like spatial or semantic properties. This means Laws can use the exact same mechanisms (e.g., Prophetic Rete) to observe or modify time as they use to observe or modify a Person's inventory or a Zone's boundaries.

Without "No Black Box", `Timeline`s would be opaque objects that only the C++ engine could advance, reducing Time from an authored ontology back to a hardcoded engine constraint. By combining these principles, Time becomes fully governable by the same semantic rules as everything else in Earthcall.
