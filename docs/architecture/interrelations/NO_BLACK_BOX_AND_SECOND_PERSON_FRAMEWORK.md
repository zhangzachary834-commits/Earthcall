## Thoughts on Integration and Interrelation
In Earthcall, the "No Black Box" doctrine allows direct state mutation via `PropertyPath`, which inherently lacks actor context. This interrelates with the "Second Person Framework", which mandates signed consent for actuating a Person, creating a tension resolved through bridges like `TransferPolicy`.
