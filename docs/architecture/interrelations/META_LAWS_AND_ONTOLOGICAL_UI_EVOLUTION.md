## The Interrelation

Earthcall mandates that user interfaces are not black-box widgets but are Formations of spatial Objects governed by Laws (Ontological UI). Simultaneously, Earthcall allows Laws to modify the properties of any Object, including those that make up a UI.

This creates a profound recursive capability: **Meta-Laws**.

When a Person uses a rudimentary UI (e.g., a basic canvas with mathematical inputs) to author a new Law, that new Law can be directed to modify the properties of the UI itself. The very instruments used to generate ideas and author logic are upgraded by the logic they produce.

### Innovation at the Speed of Thought
Because the UI is just another Formation of Objects, a Person can write a Meta-Law that refines the Law-authoring interface. For example, a Law can be written to automatically resize buttons based on context, project different 2D visual representations of Law states, or embed the authoring interface onto the back of a 3D Object in the world.

This means the platform evolves organically. The environment becomes a rich biome where the tools for creating Laws are constantly refined by the Laws themselves, enabling unprecedented expressiveness and eliminating the barrier between "using" software and "developing" software.
