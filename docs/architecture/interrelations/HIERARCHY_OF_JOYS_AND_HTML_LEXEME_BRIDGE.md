# Hierarchy of Joys and HTML Lexeme Formation Bridge

**How the ingestion of foreign web state is subordinated to the liturgical ranking of Earthcall, allowing Persons to order secular data toward their authored telos.**

## 1. The Asymmetry of Foreign State and Authored Order

The `HTML_LEXEME_FORMATION_BRIDGE.md` establishes that foreign web state (a DOM tree) is ingested into Earthcall as an ephemeral mirror of Lexemes and Relations. While this allows a page to be legible to Law, the HTML page itself arrives fundamentally *unordered* by Earthcall's telos. The webpage has its own domain semantics (search results, social feeds, articles), but it lacks any inherent standing in the `Hierarchy of Joys`.

The `HIERARCHY_OF_JOYS.md` doctrine insists that ranking and ordering are not derived from arbitrary enums or string matching, but from a depth-bounded walk along `grounds` Relations toward a foundational root (typically `lexeme.christ`).

When the HTML Bridge mirrors a document, the resulting Formation is structurally unranked (`-1`). It has no intrinsic `telos` path connecting it to the Hierarchy. If left in this state, foreign data cannot govern, outrank, or claim priority over any authored Earthcall being that participates in the Hierarchy.

## 2. Capture and Liturgical Ordering

To make foreign data meaningful, a Person must not only capture it into durable Earthcall identity, but actively order it.

When a Person selects an ingested DOM Formation (e.g., a legible search result) and crystallizes it into a durable Earthcall Category or Object, they must author its `telos`. This act of assigning a telos binds the previously secular foreign structure into the liturgical ordering of the Zone.

Because ranking is resolved by how close a being's `telos` sits to the root via `grounds` Relations, the Person determines the exact dignity the ingested information holds within their world. An article about medicine might be ordered toward `lexeme.healing`, which `grounds` toward `lexeme.love`, giving it a distinct rank. A captured advertisement, if captured at all, might remain unranked or bound to a terminal telos disconnected from the primary root.

## 3. The Integration Seam

The architectural intersection relies on the fact that both systems use `Lexemes` as their primary currency.

- The HTML Bridge mirrors DOM elements as ephemeral `Lexemes`.
- The Hierarchy of Joys models telos as `Lexemes`.

Because the foreign mirror does not instantiate new C++ domain classes (like `HtmlElement` or `SearchResult`), it outputs pure Lexeme Formations. These Formations are immediately compatible with the `telos` property path and the `grounds` Relation. The Person authors a Law that says: "When this specific structure of Lexemes appears in the foreign mirror, capture it, and bind its `telos` to X."

There is no need for a bridge-specific adaptation layer to make web data rankable. The universal vocabulary of Lexemes ensures that the output of the HTML Bridge can be seamlessly integrated into the structural proofs required by `satisfiesJoyBounds()`.

## 4. Rejection of Implicit Ranking

If a foreign webpage attempts to self-declare its importance (e.g., via `<meta name="importance" content="high">`), the bridge will faithfully mirror that attribute as an authored property of the DOM node. However, this property has no authority to bypass the Hierarchy of Joys.

The `telos` path is a first-class property governed by Earthcall Law, not a blindly inherited web attribute. An AI agent or foreign script cannot inject a high-ranking telos into a Person's world because doing so would require writing to the `telos` property of a durable being, which is guarded by the `TransferPolicy` and the Person's own authored constraints. The Hierarchy remains unpolluted by foreign self-aggrandizement.
