## The Interrelation

The `HTML_LEXEME_FORMATION_BRIDGE.md` establishes that a foreign website's DOM is pulled into Earthcall as a native Lexeme Formation, allowing Persons to author Laws over the resulting structure. The `SECOND_PERSON_FRAMEWORK.md` explores what happens when multiple Persons inhabit the same ontological space.

When these two frameworks intersect, a profound asymmetric reality problem emerges:
If Person A pulls their local browser's DOM into Earthcall, that DOM becomes an in-world Formation governed by the active Zone's Laws. Person B, existing in the same Zone, can perceive and interact with this Formation.

However, the "Act" cycle (Syncing Back) of the HTML Bridge requires sending DOM mutations back to the originating browser. If Person B authors a Law that modifies a Lexeme originating from Person A's browser:
1. The Formation in Earthcall updates natively for both Persons.
2. The Syncing Back mechanism routes the DOM mutation back specifically to Person A's local Foreign modality (their browser), because Person B does not possess the originating browser state.

This interrelation means that Foreign State, once translated into Native Ontology, becomes a shared, multiplayer substrate, even if the eventual "Act" is executed asymmetrically on only one participant's local hardware. The Second Person Framework guarantees that Person B has the authority to interact with the meaning of the HTML, while the HTML Bridge guarantees that the meaning maps back to the correct physical browser.
