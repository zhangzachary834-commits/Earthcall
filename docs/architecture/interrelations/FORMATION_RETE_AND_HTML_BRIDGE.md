## The Interrelation

The "HTML Lexeme Formation Bridge" translates a foreign website's DOM into Earthcall's native structural vocabulary (Lexemes and Relations). Because this translation produces identical structural artifacts to natively authored beings, the "Formation Rete" requires zero adaptation to process foreign websites.

When a website updates, the Bridge emits these changes as standard ontological graph mutations. The Rete, already optimized to match subgraph patterns and execute Laws, natively indexes and pattern-matches against these HTML mutations as if they were native game objects. This unified processing pipeline ensures that authored Earthcall Laws can react to a DOM node changing class with the exact same latency and mechanism as a physical object changing state.
