# Zone Overlap and Foreign Modality

Earthcall's integration with external software (Foreign Modality) involves decoding external states into native Singularity structures, mapping them into specific `Zones`.

When a Zone hosting these imported, foreign-originated structures overlaps with a native Earthcall `Home` or `Community Zone`, jurisdictional conflicts arise. If an external calendar app is mapped as an Earthcall Zone and placed within a Person's Home, which Law dictates interaction?

The interrelation dictates that Native Zone Laws maintain supremacy regarding spatial arrangement and core interactions (e.g., movement, visibility), whereas Foreign Modality mappings hold authority over the intrinsic logic of the imported Objects (e.g., date calculation in the calendar). This ensures that the foreign logic is preserved while remaining physically subjected to the human-authored Laws of the Home.
