## Thoughts on Integration and Interrelation
In Earthcall, "Interaction-as-Law" rejects traditional UI widgets in favor of pointer events interacting directly with Laws. This architecture interrelates with "Direct Screen Forms", which evaluate OntoMath expressions directly at framebuffer sample centers via `ScreenChannel.cpp`, rendering UIs without underlying physical Objects or Meshes.
