
## Bound authoring doctrine
The agents previously interpreted bounds like `kMaxChainRounds` as immutable C++ doctrine. Zach has clarified that while having bounds is doctrine, their exact values should be authorable by Persons (e.g. via Metalaws) so the machine is not a black box. See `docs/Reflections on Earthcall's Progression/Reflections on the Substrate/When_Bounds_Are_Doctrine_And_When_They_Are_Not.md` for context.
