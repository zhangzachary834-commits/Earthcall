✅ **Port the salvageable half of `claude/earthcall-event-bus-events-d6o4xm`, retire the rest** — done and verified (2026-08-31): that branch forked 2026-05-29, before `0630d616`'s ontology directory reorder and before `Game.hpp`/`Game.cpp` were retired (`52689ee3`); a plain `git merge` reconfirmed this — it resurrected `sight-cpp/src/Core/Game*` at a dead path and left five real content conflicts. Its two ideas that predated the current architecture are now superseded and were **not** ported: a static `Core::EventType` enum registry (Refusal #3 — `ECA::Event.type` is already a free `std::string`, 19 kebab-case names in live use, e.g. `person-logged-in`, `zone-entered`) and `Person::defineEvent`/`raiseEvent` with a polled condition (superseded by `Law::Activation::OnBecomeTrue`, the Rete-backed edge-trigger every Singular already gets for free). What **was** ported, as `ECA::Event{"...", subject, object, Moment}` publishes matching the existing convention: `zone-exited` + `zone-loaded` in `ZoneManager::switchTo` (`src/ZonesOfEarth/ZoneManager.cpp`, alongside the pre-existing `zone-entered`); `security-event-logged` in `SecurityManager::logEvent`; a foreign caller's own event name admitted to Law under `EarthcallAPI::_notifyEvent` (mirrors `Person::raiseEvent` for the API channel); `web-page-loaded` in `WebView::navigate`; `menu-opened`/`menu-closed` in `Menu::open`/`close`/`toggle`. All five object files rebuild clean. Raw device-level key/mouse events from the branch were deliberately **not** ported — `LocomotionChannel`/`InteractionChannel` already publish the derived *meaning* (`jump-started`, `locomotion-started`, hover), and a per-move `MouseMovedEvent` would have been a level, not an edge (Non-negotiables). **Remaining, deliberately deferred:** `SaveSystem::writeSaveData`/`readSaveData` (`src/Singularity/Storage/SaveSystem.cpp`) still publish nothing on save/load start or completion — genuinely still a gap, but that file has several early-return paths, an ambiguous empty-json-on-failure return, and an async cloud-upload callback, so it wants its own careful pass rather than a rushed insertion. The branch `claude/earthcall-event-bus-events-d6o4xm` itself can be deleted once this lands; nothing further should be merged from it.
