✅ **Fix the build: `WebSocketServer.cpp` API drift, a macOS-only link error, two stale law tests, and two mangled-string test files** — done and verified (2026-08-31), all pre-existing and unrelated to the event-bus port above. (1) `src/Singularity/Network/WebSocketServer.cpp` called `ConditionNode::Op::Neq/Lte/Gte` (renamed `Ne/Le/Ge`), passed a `PropertyPath` to `ActionNode::set` (takes `const std::string&`), and called nonexistent `ActionNode::block` (renamed `ActionNode::parallel`, "children conceptually simultaneous" — the right semantics for two independent position writes). (2) `CMakeLists.txt`'s very recent `uuid` link (added in `322db65a`, for `Lexeme.cpp`'s `uuid_generate`) broke every non-`earthcall_webgpu` target on macOS: `<uuid/uuid.h>`'s symbols ship in libSystem there, and there's no separate `libuuid` to find — gated the link behind `if (NOT APPLE)`, matching how `earthcall_webgpu`'s own link list already omitted it. (3) `tests/law/add_relation_action_test.cpp` and `tests/law/synthesis_studio_app_test.cpp` predated a real API move — `Universe::Provider`/`RelationProvider` changed from return-by-value to fill-a-reference, `Zone` no longer holds relations directly (now a standalone `RelationManager` reached via `Universe::setRelationProvider`/`setRelationRegistrar`, the pattern `control_patterns_test.cpp` already established), `CategoryManager::get`/`create` return `shared_ptr<Object>` not raw pointers, `Object::setIdentifier` is now `setObjectID`, `Relation::getType()` is now the public field `.type`, and `ConditionNode::evaluate(being)` is now `.compile()(probe, being)` (an `ECA::ConditionPredicate`). Rewrote both call sites to the current API without changing what either test actually asserts; both pass at runtime (`add_relation_action_test`: 3/3; `synthesis_studio_app_test`: 4/4). (4) `tests/singularity/no_black_box_test.cpp` and `tests/singularity/gpu_mastery_test.cpp` (both touched by `390a5ea9` "Background colors must not be a black box") had `\n` escapes mechanically replaced with literal newlines inside string literals in ~10 spots total, breaking the lexer; restored the escapes. (5) `synthesis_studio_app_test` opens its fixture by a bare `"saves/worlds/synthesis_studio.json"` path, but ctest's default `WORKING_DIRECTORY` for an `add_test()` target is the build tree, not the source tree (unlike `test_observation_load_test`'s equivalent fixture, which is optional and just skips when the CWD doesn't have it — this one is the test's actual subject, so it can't); added an explicit `WORKING_DIRECTORY ${CMAKE_SOURCE_DIR}` for just that test. **Verified**: `cmake --build build -j8` exits 0 with zero errors; `ctest --test-dir build --output-on-failure -j4` is 81 registered, 80 pass — the one failure is the pre-existing, documented `smooth_tessellation_cache_test` (Bugs.md #11), unchanged. `earthcall` and `earthcall_webgpu` both build and link.
