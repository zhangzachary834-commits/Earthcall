Newborns are now named by concept **and birth** via `ObjectIdentity::generateConceptMemberId`, drawing the birth number from the same counter as `generateObjectId`; `claimIdentifierAtLeast` learned the `.birth-N.` form so a reloaded world cannot reissue a live identity. Guarded by `tests/shape_generator_law_test.cpp`.

Added the `active3DMode == "Create"` guard, an `ImGui::GetIO().WantCaptureMouse` guard (the bypass polls GLFW directly, so this window's own buttons spawned cubes behind themselves), and moved the click-edge tracker above both gates so a gate opening mid-hold cannot read a held button as a fresh press. **Needs a human click to confirm** — see Feature-sized item 2. Open sibling: the same early-return is why the armed law now places at the origin (audit 1.1); loading `saves/tests/shape_generator_3d_law.json` still double-spawns via a second being `law-3` (audit 1.2).
