9. ✅ **Chess: clicking a pawn does nothing in-app, while `chess_app_test` passes** — done and verified (2026-08-24). Two root causes resolved: (1) In `InteractionChannel::step()` (`src/Singularity/Input/Interaction/InteractionChannel.cpp`), window coordinates from `MouseHandler::getCursorPosition()` (in screen/window points, e.g. 1280x720) were converted to NDC against `viewport[2]/viewport[3]` (framebuffer pixels, e.g. 2560x1440 on macOS Retina displays), halving the ray coordinates and causing raycasts to miss the board completely. Fixed by factoring in window-to-framebuffer DPI scale `scaleX = fW / winW`, `scaleY = fH / winH` (and centering ray when cursor is locked). (2) Upgraded `scripts/author_chess.py` to fix anti-diagonal path blocking and implement full distant sliding checks (Queens, Rooks, Bishops) via staged coordinate evaluation in the ECA cascade. Output strictly scoped to `saves/worlds/chess_app.json` and `saves/zones/Chess/zone.json`. Guarded and verified in `tests/law/chess_app_test.cpp` and `scratch/probes/chess_app_probe.cpp` (all 66 CTests pass).
