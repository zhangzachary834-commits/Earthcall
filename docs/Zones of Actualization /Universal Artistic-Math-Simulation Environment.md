# Universal blah blah blah I dont wanna type that mouthful (fine acronym AMS) engine  

Authored by Zach

This is one of the things that originally inspired me to create Earthcall in the first place.

Basically, you have to realize every single digital art program is essentially a locked-geometry thing with specific Laws about how pixels are applied.

Mathematical/gemoetry/modeling engines are precise things that can be authored in many ways but no matter how many ways its limited to the engines pre-specifications. New laws can't be authored at runtime. You're stuck to whatever the interface gives you—typing it parameters manualy, etc.. If you could modify it with the granularity and human-ness of a digital art studio, that would be incredible.

And physics. Realistic simulation is essentially the latter two but with real-time change instead of merely authoring static pictures.
