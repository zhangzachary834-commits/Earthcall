## Reproduced

1. **P1 · A fast left click can actuate the wrong being.** Press and release over A, then move to B before `InteractionChannel::step`. The channel emits both `object-pressed` and `object-clicked` on B. The callback queues only a boolean, and the drain gives every transition the same final pointer, ray and modifier readings. One stationary same-batch click works. Longer frames widen the interval in which motion and button edges can be collapsed. [Callback](../../src/Singularity/Core/EngineInit.cpp#L834) · [Frame sample](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L596) · [Replay](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L718)
2. **P1 · Scaled 3D geometry can win a pick through a closer object.** A cylinder at the origin stretched 4× along Z reported a hit at `t = 4.5` from `(0, 0, 20)`. Its front surface is at `z = 2`, so the world-space distance is `18`. A cube with a front face 9.5 units away lost the pick. The channel reported `pointerWorld.z = 15.5`, outside both surfaces. `raycastFace` normalizes the transformed direction and returns local ray distance directly for complex shapes, Fields and patches. Smooth and primitive paths convert by dividing by `dirLen`. `pickSurface` compares all those distances as world-ray parameters and uses the winner's parameter to reconstruct the point. The runtime witness covers the cylinder. Fields and patches have the same omitted conversion in source. [Raycast](../../src/ConstructedBeing/Singular/Object/ObjectRaycast.cpp#L83) · [Picker](../../src/Singularity/FirstMoverOntology/FirstMoverWindowTools/Tool.cpp#L142)
3. **P2 · Release can skip click slop.** On a single 60-point plate, press at `x = 10` and first sample the displacement at release at `x = 45`. The channel emits a click with the default 12-point slop. The same motion sampled once while held emits a drag and no click. Slop is evaluated only while the sampled button is down. The right and middle paths use the same shape. A full excursion and return between frames also leaves no movement record. [Left release](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L430) · [Right and middle](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L481)
4. **P2 · Rapid right and middle clicks disappear.** Injecting each button's press and release before one production `step()` yields one left click and zero right or middle clicks. Spreading the right and middle pairs over two steps yields one of each. GLFW changes both levels and delivers both callbacks, but Earthcall forwards only left-button transitions into the queue. [Callback](../../src/Singularity/Core/EngineInit.cpp#L850) · [Button polls](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L625)
5. **P2 · Authored key commands can fire zero or two times.** The Law pattern filters `key-pressed` against `@interaction-channel.lastKey`. With an `e` command and one Law tick after both keys, `e` then `q` fires zero times and `q` then `e` fires twice. Both events reach the bus in both cases. The deferred Law reads the shared latest value for each occurrence. A key following a queued click in the same input batch reaches the previously focused being because `noteKey` publishes in the callback and pointer focus changes later. Releasing `q` also clears `keyDown` while `e` is held. [Key channel](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L575) · [Authored key pattern](../../src/Singularity/Input/Interaction/ControlPatterns.cpp#L264) · [Law evaluation order](../../src/Singularity/Core/Engine.cpp#L386)
6. **P2 · A held gesture can transfer to a distinct being with the same identifier.** Press one Object, then replace the reachable set with another Object bearing the same slug. Release and click both address the replacement. The original gets no release or reach-exit, and its `hovered` flag remains true while it is out of reach. The channel retains a string and prefers whatever currently reachable Object has that string. This is a reachable-set fixture, with two distinct live instances. The corresponding live Zone-switch path was not run. Zach's authored decision about whether leaving reach cancels the original gesture still stands. [Reach and resolution](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L127) · [Reach transitions](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L360)
7. **P2 · Re-enabling the channel while held can manufacture a click.** After a press, set the channel down and lift it again while the physical button stays down. The channel publishes a release on disable, a new press on re-enable, and a click on the eventual physical release. No `object-press-cancelled` is emitted on disable. The derived `leftDown` level doubles as the transition history. [Channel gate](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L310) · [Button transitions](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L400)

## Further contract gaps

- **Pick priority.** The probe reproduced a negative-priority 3D object intercepting a ray, while negative-priority 2D candidates are skipped. A farther 3D Object with priority `100` is discarded before the 2D comparison when a nearer 3D Object intersects the ray. The nearest-3D rule may be intentional for occlusion. The negative-priority opt-out and its effect on occlusion need one explicit authored contract. [Priority comparison](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L232)
- **Hover participants.** The probe saw the Person on `object-clicked` and an empty `@event.object` on `object-hover-entered`. Hover publishes from `Object::updateHoverState`, bypassing the participant convention in `InteractionChannel::publishEdge`. [Object hover publication](../../src/ConstructedBeing/Singular/Object/Object/ObjectEvents.cpp#L77)
- **Other frame-sampled input.** Source inspection shows wheel callbacks accumulate an offset and target the final hit. Opposite offsets in one frame can sum to zero, and distinct target locations collapse. The global compatibility event `mouse-clicked` fires on press before the channel's gesture check. Its shape-generator consumer reads the frame's later placement transform. Grounded jump also detects a press by polling `Space` each frame, so a full tap within a poll batch has no rising level. These paths were traced in source. [Wheel](../../src/Singularity/Input/Interaction/InteractionChannel.cpp#L718) · [Global mouse event](../../src/Singularity/Core/EngineInit.cpp#L862) · [Shape generator](../../src/Singularity/Core/CreationChannel.cpp#L171) · [Jump](../../src/Singularity/Input/Locomotion/LocomotionChannel.cpp#L292)
