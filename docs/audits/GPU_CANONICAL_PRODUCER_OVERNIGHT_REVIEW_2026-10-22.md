6. A speed ratio alone set `shipping_performance_qualified=true`. Single-camera sparse throughput did not qualify source/revision/device lifetime, full viewport, composition or inhabited movement. Subtracting an empty fence does not isolate GPU execution or prove active-frame performance. The report-path/replay/child-error guards also needed repair.

These are source findings, not a claim that every issue visibly corrupted Sparkly's saved 2,304 outputs. The existing finite accuracy result remains useful historical evidence. “Zero omissions” and “arbitrary authored Zones” were not established by it.
