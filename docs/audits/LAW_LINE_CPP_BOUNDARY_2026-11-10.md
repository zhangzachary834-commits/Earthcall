# Where Law Line meaning still lives in C++

*Codex · GPT-6 · session `01a1c94b-85cd-7702-bdb8-43ffa1a36691` · 2026-11-10 22:54 PST · source revision `cada12d38`.*

Zach asked whether Law Line has a bespoke C++ Lexeme-to-Law compiler, transformer, or traverser beyond what the machine irreducibly needs. His [TerminalLine decree](../addendums/terminal_line_naming_and_modality_scope_addendum.md) admits a reader for the Terminal modality and places semantic authority in Lexemes, Relations, Laws, and Metalaws. The minimum-maximum principle from [AGENTS.md](../../AGENTS.md) supplies the admission test. This audit follows the implementation recorded in the [Law Line task](../Agenda/Tasks/Specific%20Tasks/Law%20and%20Reasoning/Law_Line/Law_Line.md).

**Yes.** The current C++ reader also classifies meanings, constructs executable models directly, and decides parts of how those models compose. Several newer forms genuinely delegate lowering to authored Metalaws. The most consequential exception is binding syntax, where an authored compiler can explicitly refuse and the Terminal can still adopt its own prebuilt action.

## Findings

1. **Binding forms can discard an authored compiler refusal.** `share`, `claim`/`unique`, `borrow`/`observe`, and `derive` have canonical C++ spellings. Their parser branches build an `ActionNode::Map` through the corresponding binding factory before they consult an authored compiler. The request already carries the native action's function and bindings. When the compiler returns an action, it wins. With no action, the branches return the prebuilt node and ignore the error, including an explicit refusal or a conflicting/invalid output reported by the compiler. The lower-level action still runs through normal Law application and TransferPolicy. The bypass is at **authoring and interpretation**. [Canonical words](../../src/Singularity/Terminal/LawSentence.cpp#L1705) · [Binding branches](../../src/Singularity/Terminal/LawSentence.cpp#L1368) · [Compiler error handling](../../src/Singularity/Terminal/TerminalChannel.cpp#L1692)

2. **Ordinary sentences have a native Lexeme-to-model path.** `TerminalChannel::vocabulary` enumerates Relations, filters by the configurable `lexemeRelation`, and passes each denoted Law to `LawSentence::classify`. C++ inspects the model and decides whether an empty field is an argument hole, a Set operand denotes a value, or a Law supplies a complete action or preset. It also installs a canonical vocabulary independently of Relations. Literal Set, Add, Scale, Publish, Spawn, Destroy, AddProperty, RemoveProperty and AddRelation construct action nodes directly. Plain comparisons, Identity, Related, Overlaps and kind tests likewise construct condition nodes directly. The parser also chooses condition grouping and precedence, action sequencing, preset merge rules and default scope. A Person can author aliases, values, presets and closed action fragments today. Changing those positional argument rules or the native composition defaults still requires C++. [Vocabulary traversal](../../src/Singularity/Terminal/TerminalChannel.cpp#L987) · [Model classification](../../src/Singularity/Terminal/LawSentence.cpp#L1773) · [Conditions](../../src/Singularity/Terminal/LawSentence.cpp#L640) · [Direct actions](../../src/Singularity/Terminal/LawSentence.cpp#L1297) · [Composition](../../src/Singularity/Terminal/LawSentence.cpp#L1489)

3. **The reader can choose meaning by enumeration order.** For ordinary value words, the matching loop collapses equally long spellings by opcode. Two value Laws with the same spelling and distinct literal values can therefore become one candidate before the resolver sees them. Closed action fragments of the same opcode go through that same deduplication rule. Where ambiguity does reach the resolver, it applies Laws that explicitly target the Terminal and reads a shared `ambiguity.resolved` after the loop. In the fixture, two matching resolvers proposed different meanings and the last writer's choice prevailed. Authored compiler outputs already have an explicit conflict check. Lexeme identity and any authority to choose between meanings need to survive the whole read. [Candidate deduplication](../../src/Singularity/Terminal/LawSentence.cpp#L284) · [Ambiguity dispatch](../../src/Singularity/Terminal/TerminalChannel.cpp#L1517) · [Compiler conflict check](../../src/Singularity/Terminal/TerminalChannel.cpp#L1724)

4. **The authored compiler path still has a Terminal-specific host.** `compileByMetalaw` reflects the request into a registered Property, scans the Law register, and directly calls `applyTo` on Laws explicitly targeting the Terminal. It does not use a compilation-trigger lookup to select that set. The template traversal itself is a bounded structural operation over data, substituting `$slot` JSON pointers with an optional authored `$default`. Around it, Terminal C++ recognizes slot names, scans templates for used arguments, interprets output envelopes, and checks particular action kinds. The reader also gives the argument names `children` and `expression` special typed treatment and reserves a positional initializer form for `properties`, `authored`, and `registered`. Arithmetic comparison sensing constructs a difference or flips a comparison before the authored condition compiler sees it. These choices can be separated from byte reading. A bounded record traversal is defensible as generic machinery, while its implementation inside Terminal and the policy of which Laws get invoked are separate choices. ## Where authored meaning already works

The Terminal senses `terminal-line-entered`. Seeded hearing and speaking Laws decide whether to request authoring. The spoken line can carry a complete denoted action tree or an authored preset. In the parameterized path, saved Metalaws choose the models for Object and prototype creation, individual Create initializers, path-copy assignment, arithmetic conditions, named actions, and typed values such as Screen fields. Batch policy authorizes exact source-order adoption. For example, the isolated fixture changed the Object compiler's output to Publish and the same Create sentence produced the Publish model. Disabling that compiler refused the sentence. That is a working precedent for moving interpretation out of the remaining branches. [Hearing and speaking Laws](../../scripts/seed_law_line.py#L364) · [Create compilers](../../scripts/seed_law_line.py#L179) · [Named actions and batches](../../scripts/seed_law_line.py#L548) · [Changed and missing compiler witnesses](../../tests/singularity/law_line_zone_test.cpp#L408)

The machine-facing floor includes TTY byte and key input, secure presence input, rendering the editor, identifying source spans and delimiters, and bounded reading of structural values. The shared model layer has its own work of validating typed models, enforcing authorship and authority, adopting Laws, and executing existing opcodes. Terminal-local syntax can remain legible as syntax while the mapping from a surface form to an executable effect is authored. Nothing in this trace establishes that the present bespoke traversals, semantic classification, or composition defaults are irreducible. ## Follow-through

Start with the binding bypass. Provide authored compilers for all four forms and preserve their surface spellings and existing serialized models. Carry the sensed paths or expression into the request and let the selected compiler supply the binding model. Exercise missing, explicit-refusal, malformed, and conflicting responses before removing the direct fallback. A save containing a previously compiled `Map` continues to enter through the existing model codec. [Property binding task](../Agenda/Tasks/Specific%20Tasks/Rendering%20and%20OntoMath/Property_Storage_and_OntoMath_Binding/Property_Storage_and_OntoMath_Binding.md)

Preserve distinct denotation identities through candidate collection and resolve conflicts through authored authority, with a refusal when no authorized meaning wins. For the wider migration, use the working authored invocation path as the reference. Let the Terminal sense operands and structure, give authors control of argument interpretation and model composition, and put typed validation in the owning model layer wherever its contract is shared. Demonstrate a new surface form that compiles through authored data with the same binary. Keep the Terminal grammar scoped to the Terminal modality.

The last resolver's inequality was adopted. Same-opcode closed action deduplication is a source finding.
- This audit used isolated fixtures, with no engine changes or live save edits. The proposed migration remains open.
