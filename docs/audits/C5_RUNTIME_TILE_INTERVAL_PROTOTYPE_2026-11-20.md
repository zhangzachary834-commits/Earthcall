## Runtime classification and publication

The classifier reads the current inverse view-projection matrix, eye, viewport and current valid medium boxes every frame. It does not read authored names or choose a fixed legacy partition. There is no retained camera-mask cache to become stale on pose, resize or box edits.

It bounds primary-ray reconstruction over each tile's full coordinate rectangle, including every pixel centre. It follows the actual slab function's `safeRd`: a component with magnitude below `1e-8` becomes **positive** `1e-8`, including small negative inputs. A range crossing that branch keeps both possibilities. A denominator interval containing zero supplies no slab constraint on that axis. Nonfinite, degenerate or out-of-profile arithmetic retains wider work. Camera near/far planes are not used as transport endpoints.

For each box, interval slab entry/exit bounds can prove absence only when the greatest lower entry bound exceeds the least upper exit bound. Otherwise the box remains a candidate. Tile-mask union gives the enclosing viewport cohort. The most frequent strictly smaller mask with at least two members is a second physical cohort; a tile may use it only if its candidate mask is a subset. Other tiles use the enclosing cohort. This prototype bounds publication to two cohorts; it does not assert a universal profitable media width. Identical horizontal runs merge down successive rows.

Each pixel receives one complete ordinary unrouted Joint answer. Retained media keep original order and execution-family tags. The proxy/union header comes from **all original valid inputs**, even for smaller physical programs. The original whole-set proof-trim choice is explicitly retained for both subsets. Depth clipping, event/chord rules, quadrature rule, early termination and one `(L,T)` continuation remain authoritative. No independent framebuffer split, chronology invention or deletion based only on sampled optical zeros occurs.

The prototype applies inside the existing fallback only, with no active routed/First-activity producer, and only to its supported ordinary diagnostic mode. Other paths remain original. More than 63 inputs retain the original path because this scratch mask representation is bounded; that is not an authored cardinality law.

## Numerical dependency autopsy

Three interval representations were tested without changing the 64 × f32-epsilon error allowance or the shader ray arithmetic:

1. Independent normalized-component intervals assigned about 39.7% of reverse to Joint4.
2. Keeping normalization's shared positive length correlated raised that to 63.0%. Subdivision added work without improving that coverage.
3. Keeping the homogeneous divisor correlated raised depth-zero coverage to 77.7%.

The named source of persistent uncertainty was `H.w`: reverse has row terms near `-9.99805` and `10.00005`, leaving about `0.00199986`, plus small x/y terms. Independent divisions amplify that common uncertainty separately in every coordinate. The final host model bounds the equivalent positive ray scale using `sign(H.w) × (H.xyz − eye × H.w)`, with an explicit allowance for the original f32 dot/division/subtraction operations. It does not replace shader coordinate production with this algebra.

The model additionally refuses uncertain divisor sign, tiny divisors, possible zero/underflowing normalization, extreme world reconstruction and nonfinite values. Its declared research profile uses divisor magnitude above `1e-30`, reconstructed-coordinate bounds below `1e12`, and a positive source-direction length bound above `1e-12`; these are conservative admission limits, not quadrature thresholds. Subnormal allowances remain in the envelopes.

**The model is conditional.** A full enclosure of all retained native Fast-mode transformations has not been established. WGSL permits reassociation and gives inherited accuracy for normalization, so source parentheses alone do not establish a native execution theorem. [WGSL numerical contract](https://www.w3.org/TR/WGSL/#floating-point-accuracy); [earlier observed native profile and its explicit unresolved boundary](VOLUME_SUPPORT_NATIVE_PROFILE_2026-10-12.md). Neither this prototype nor the tests reopen or promote that support-certificate research.
