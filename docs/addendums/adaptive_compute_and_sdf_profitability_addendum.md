## Integration and Interrelation

The core challenge documented in the Direct Profitability Artifact is that while we can generate a rich spatial theorem (the SDF Prophetic Rete), evaluating it directly on the hot path (every frame, per ray) introduces an unacceptable interpretive tax (e.g., 83,649 consultations for 144 saved exact samples). The solution isn't to abandon the theorem, but to recognize it as a derivation spine rather than a frame-time representation.

This directly necessitates the architecture described in Adaptive Compute Moments. If the rich theorem is too expensive for the hot path, we must compile it down to a "direct artifact" (like the maximal axis-adjacent positive runs mentioned in the SDF document). However, compiling this artifact takes time. We cannot pay this compilation cost on the main thread without causing a frame tax.

Therefore, Adaptive Compute Moments provide the exact temporal domain required to distill the SDF Prophetic Rete into a direct profitability artifact. The slow adaptation process (Adaptive Compute) is what safely builds and maintains the crystallized road (the Direct Artifact) without blocking the world. The world continues rendering using the best available direct artifact, while the Adaptive Compute asynchronously refines the theorem and generates a more profitable direct representation over time.
