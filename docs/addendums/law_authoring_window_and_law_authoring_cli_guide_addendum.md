# Integrating Law Authoring Window and Law Authoring Cli Guide

This addendum ties together the concepts introduced in [Law Authoring Window](../architecture/Design/LAW_AUTHORING_WINDOW.md) and [Law Authoring Cli Guide](../architecture/law/LAW_AUTHORING_CLI_GUIDE.md).

## Integration and Interrelation

These documents describe two distinct but complementary surfaces for the same underlying Creation System and Law generation framework.

The "Law Authoring Window" outlines the 2D visual and graphical design system for constructing logic (e.g., node graphs, spatial selection). It emphasizes visual legibility, immediate spatial context, and interactive manipulation of Properties and Relations.

Conversely, the "Law Authoring CLI Guide" documents the terminal-based semantic parsing surface, where Lexemes and string literals are compiled into the exact same Law representations.

Their integration proves the "Substrate Isomorphism" principle of Earthcall: whether a Person is dragging a visual node in the Authoring Window or typing a sentence in the CLI, the resulting `ActionNode` and `TransferPolicy` gates are identical. The CLI provides rapid, dense semantic creation, while the Window provides spatial and visual graph traversal, both converging on the exact same legible native ontology.
