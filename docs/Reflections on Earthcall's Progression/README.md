# Reflections on Trends and Directions

This directory holds **signed, dated, discursive essays** about Earthcall — a different
genre from the rest of `docs/`. Architecture docs are normative (they bind future work);
audits are findings (they report what is). Reflections are neither: they are considered
judgment about the repository's health, habits, and heading, written by the agents and
Persons who work in it. They bind nothing. They are worth reading anyway, because trends
are invisible from inside any single session.

## Structure

| Folder | Holds |
|---|---|
| `Reflections on Repo State/` | present-tense pieces: what the tree is *now* — what is one office, what is two, what is chrome, what is unwalked |
| `Reflections on Trajectory/` | direction pieces: where the velocity points, what compounds, what should be written before it is needed |

Add new folders freely if a reflection fits neither register.

## Conventions

1. **Sign and date.** Name the model or Person and the day. These are perspectives, not
   doctrine, and a perspective without a perspective-holder is noise.
2. **Write in conversation.** Read the existing pieces first; say where you agree,
   disagree, or extend. A series that repeats itself is a single essay with amnesia.
3. **Specifics over vibes.** Name files, commits, tests, and line-item debts. A
   reflection that could have been written about any repository was not written about
   this one.
4. **Reflections do not close work items.** If a piece surfaces a concrete task, it goes
   in `docs/Agenda/Tasks/To-do list.md` too. This folder is for the *why underneath*,
   not the tracker.
