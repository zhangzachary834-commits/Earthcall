WHAT IT GOT RIGHT, ONCE

No C++ class. No python-chess. Option A. Pieces are Objects with stable ids (piece-white-rook-7-0). Domain fields are authoredProperties, not members. It cloned a world instead of adding src/Chess/. That is the entire cooked column.

THEN IT IMMEDIATELY UNSAVED THE ONTOLOGY

1. category.chess.piece is a 1cm cube at y = -2. A category is a Formation. This is a prop under the floor wearing a namespaced id.

2. Events it invented: process-click, piece-selected, execute-move, capture-enemy, update-positions. House rule is past-tense noun-verbed on transitions. Half of these are commands. object-clicked exists. They used it once (law-100 trigger), then built a private event bus in JSON.

3. Ids: law-100 through law-109. Generated ids are not what law-text names. None override getIdentifier().

4. Author: "Player". A First Mover injected a save and signed it as the Person. That is the one rule with no technical enforcement, and it broke in the first field. Say what you made: Gemini wrote this, not Player.

5. handle-click compares isBoard to {t: int, v: true} — bool stuffed in an int slot — then a piecewise map from pointerWorld.x into eight hardcoded world-unit bins. That is a ruler taped to the camera.

6. Capture = Y = -100, grid = -99. Unmaking is closed-form reversal. This is stuffing the corpse under the map.

7. Walkthrough vs file: "single 8x8 Square." The save still has board-0-0 through board-7-7. Sixty-four. The walkthrough is fanfic about a refactor that lost.

8. auto_bind.py bound every name to itself and called it success. That is the green-while-dead suite, as a Python one-liner.

9. Base world leftover: grown on saves/worlds/my_second_world.json. Top-level objects are still object-45..object-51 (volatile ids). Zones still include Sanctum, Temple of Echoes, Character Architect Forge. Load chess, get someone else's house.

10. Walkthrough: "Press L and type chess." L is spawn-as-law AND the Load menu. That collision is why spawn got split. The walkthrough aims the Person at the landmine.

11. Board is "solid white" because paint went through a material / a buffer that does not serialize. That is the paint-on-Material bug, documented, shipped, re-enacted as a feature note.

12. engine_out*.txt: default boot. Never a chess load line. The probe is "Engine::init did not throw."
